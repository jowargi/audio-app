# 🎧 Headphones Catalog - React Masterclass

Веб-приложение для каталога наушников с системой отзывов и рейтингов, разработанное в рамках мастер-класса по React.

## 🚀 Технологии

- **React** - современные хуки и функциональные компоненты
- **TypeScript** - строгая типизация для надёжного кода
- **Vite** - быстрая сборка и горячая перезагрузка
- **CSS3** - современные стили и адаптивный дизайн

## ✨ Возможности

- 🎧 Просмотр каталога наушников (Apple, Sony, Sennheiser, Bose и др.)
- ⭐ Просмотр отзывов и оценок реальных пользователей
- 🔍 Фильтрация по брендам и поддерживаемым аудиокодекам (AAC, LDAC, aptX)
- 👤 Профили пользователей с историей отзывов
- 📱 Полностью адаптивный интерфейс

## 🗂️ Структура данных

Проект использует **нормализованную структуру данных** (mock API):

- `normalizedHeadphones` — товары с полями: `id`, `name`, `brand`, `type`, `maxVolume`, `img`
- `normalizedReviews` — отзывы (`id`, `text`, `rating`, `userId`)
- `normalizedUsers` — пользователи (`id`, `name`)
- `normalizedCodecs` — поддерживаемые аудиокодеки

Такая архитектура упрощает масштабирование и имитирует работу с реальным бэкендом.

## 🎯 Цель мастер-класса

Практическое освоение **React + TypeScript** на примере создания каталога наушников с системой отзывов, типизированными компонентами и работой со сложными нормализованными данными.
